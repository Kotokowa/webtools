离线下载

先确认系统架构。没有兼容显卡、不确定配置，或必须在断网时首次启动，请选标准版。

标准离线版（无需显卡）

解压后直接启动，不用安装 Python，也不需要联网。支持 Windows x64、macOS Intel／Apple Silicon、Linux x64／ARM64。

    含 GPU 加速器的离线版

    面向 Windows x64／Linux x64。显卡需为 NVIDIA Turing 或更新架构（CUDA 计算能力 ≥ 7.5），例如 RTX 20 系列、GTX 16 系列及更新型号，并安装支持 CUDA 13.0 的 R580 或更新驱动。AMD、Intel 和 Apple Silicon 不支持此 CUDA 路径。显存不足时仍会回退到 CPU。

    套装仍可用标准启动器直接离线运行。使用 GPU 时运行 GPU-accelerator 中的启动器，需 64 位 Python 3.11+，并在首次运行时联网安装依赖。安装完成后可离线；不会修改显卡驱动。
