# Water Wave Lab 本机加速器

作者：kotokowa。在线工具：https://kotokowa.github.io/webtools/water-wave/

此包只包含水波工具。需要 Python 3.11 或更高版本；首次启动会联网安装 NumPy、SciPy、Pillow、OpenCV、pyFFTW 和 zlib-ng，完成安装后可离线使用本机网页。无需安装 Node.js。

Windows：完整解压后双击 `launch-water-wave.bat`。macOS / Linux：在解压目录运行 `sh launch-water-wave.command`。启动器会打开同一套网页界面。保持启动器运行，关闭它会停止加速服务。

服务只监听 `127.0.0.1:8765`。在线网页打开时会尝试连接该地址；若服务尚未启动，启动后刷新在线页。浏览器如请求访问本地网络，应由用户确认。顶栏显示“本机 Python 加速”或“本机 Python + GPU”表示已连接；否则继续使用浏览器 Python。也可以直接使用启动器打开的本机网页。

数据仍由网页选择、恢复和保存。本机批处理每帧保存文件，已保存高度帧和完整 RMS 可在“继续”时复用。先计算各视频 RMS，再计算重复实验均值和不确定度，最后对平均 RMS 做一次聚焦分析。普通图片／视频导入仍按原方式下载结果。

在线连接仅允许 kotokowa.github.io 和该服务自己的本机页面；不向任意网站开放接口。程序不会扫描或上传未选择的本地文件。

更新时请关闭旧启动器，解压新版本到新目录后重新启动。输入数据和结果保存在用户选择的目录，位于工具包之外。

本机代码的许可见 LICENSE；第三方依赖保留各自许可。FCD 代码许可见 waterwave/LICENSE-FCD.txt。

本机引擎使用 FFTW 加速傅里叶变换、zlib-ng 压缩结果，并顺序复用视频解码器。在 Windows 上仅为当前计算进程请求高性能调度，不修改系统电源计划。恢复公式、空间分辨率和逐帧 RMS 累积保持不变；实际速度取决于电脑和数据。运行信息随结果保存。

启动器检测到 NVIDIA 驱动 580 或更高版本时，会尝试安装可选的 CuPy、CUDA 13 运行库和 FFT 组件，首次额外下载约 370 MB；不安装或修改显卡驱动。支持的 GPU 用双精度执行载波解调和相位解包裹，其余步骤仍在 CPU 完成。没有兼容显卡、依赖安装失败或运行时显存不足，会使用 CPU。小于 512×512 像素的任务也直接用 CPU。排查显卡问题时可设置环境变量 WATERWAVE_DISABLE_GPU=1 后启动。
